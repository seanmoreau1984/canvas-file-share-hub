## About CANVAS

CANVAS is a sharing project that lives on the web. Its purpose is deliberately narrow: make it easier to publish and pass along content through the browser. Instead of layering on a complicated interface, it keeps the experience simple, which suits lightweight distribution and fast access.

Since it runs on the web, you can open CANVAS and start using it without going through a separate desktop installation. That makes it a reasonable choice for anyone who wants a browser-first sharing tool with minimal setup and a clear path from opening the app to sending or receiving content.

## Installation

1. Download or clone the repository:
   - `git clone https://github.com/seanmoreau1984/canvas-file-share-hub.git
2. Move into the project folder:
   - `cd canvas`
3. Open it in a browser, or serve it with the local web server of your choice.

When deploying to a static host, put the project files somewhere your web server can reach them, then open the main HTML entry point in your browser.

## Usage

Load CANVAS in a browser and follow the on-screen sharing flow to publish or access content.

A typical run looks like this:

1. Start the web app.
2. Load or prepare the item you want to share.
3. Complete the sharing action through the interface.
4. Share the generated access path, or open the shared content in another browser session.

If you are running it locally, refresh the page after editing source files so the browser picks up the latest version.
